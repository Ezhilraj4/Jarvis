# MAGGI portfolio

A cinematic, responsive product portfolio for the MAGGI personal AI project. It presents the capabilities already implemented in the desktop application, including live voice, computer control, persistent memory, Research and Office Studio, background routines, the paired phone dashboard, and the God’s Eye observatory.

## Experience

- Two interactive Three.js scenes
- Original AI generated command core artwork
- Responsive layout verified at 1440 px and 390 px
- Scroll reveals and word level tagline animation
- Accessible navigation, focus states, semantic sections, and reduced motion support
- Branded favicon, metadata, legal notes, and custom error page

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run check
npm run build
```

The optional visual verifier uses a local Chrome installation:

```bash
npm run verify:visual
```

## Technology

React, Vite, Three.js, Framer Motion, and Phosphor Icons.
