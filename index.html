◎Project vision

⌘Project vision

Reasoning and explanations

Break down questions, explain steps, brainstorm, summarise information and turn a goal into an actionable plan.

Draft, rewrite, translate, outline, tutor and explain school or technical topics in a style that suits the conversation.

⌕Project vision

Camera, microphone, file access, online services and computer control need clear permissions and visible user choice.

⌘Project vision

Developer support

⌬Project vision

Hardware and IoT

Task automation

Turn repeated steps into guided workflows, with a preview and confirmation before meaningful changes are made.

How it could work

From a thought to a useful next step.

Ask in your own way

Review the response

Read or hear an answer, summary or suggested plan. Choose models and tools when those options are available.

Confirm any action

Review what a computer task will do before it runs. Edit, approve or cancel the proposed step.

Trust by design

Powerful help should stay understandable.

Jarvis is intended to work with the person using it. This portfolio runs only a scripted chat preview and optional browser speech synthesis. It does not activate the microphone, access files, save chats or control the computer.

Ask before using sensitive device permissions.
Show the action before changing a file or setting.
Make online services and local processing distinguishable.
Let people inspect and clear saved context.

Questions

Good to know before exploring.

This is a portfolio for an assistant project in development, with an interactive preview of the interface idea.

Is Jarvis ready to install?

This website does not distribute an installer. The project is an early build; check features in the actual app before relying on them.

Does the demo control my computer?

No. The chat is scripted here. It cannot open apps, change files, run commands or connect to the desktop assistant.

Can Jarvis work without internet?

Local models are part of the project direction. Offline behavior has not been confirmed as dependable, so test the installed model and app first.

Can it hear and speak?

Voice conversation is a design goal. This page can optionally read a demo answer aloud using your browser but never listens to your microphone.

Can it see images or my screen?

Visual understanding is planned. The portfolio does not request camera or screen sharing access.

Which AI models does it use?

That depends on providers or local models configured in the real app. This page does not send prompts to an AI service.

Does this site save my messages?

No. Preview messages stay in the current browser page and are not sent to a database or saved by this portfolio.

Who is building Jarvis?

Jarvis is presented as a personal AI assistant project by Ezhil Raj, an AI and electronics enthusiast.
